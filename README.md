# Nova: El Desafío Zarnathia

Videojuego de plataformas y acción en 2D ambientado en un universo futurista. El proyecto está desarrollado en Unity y cuenta la historia de Helen Nova, una policía intergaláctica enviada al planeta Zarnathia para liberar a sus habitantes del dominio del Rey Varkon.

## Historia

El tiránico Rey Varkon ha sumido Zarnathia en el caos. Helen debe atravesar sus territorios, superar trampas y obstáculos, enfrentarse a criaturas hostiles y reunir tres llaves sagradas. Con ellas podrá abrir la Cámara Secreta y combatir al rey para devolver la paz al planeta.

## Cómo se juega

- Explora los niveles de Zarnathia.
- Salta para superar plataformas y obstáculos.
- Enfréntate a los enemigos con ataques cuerpo a cuerpo o disparos.
- Recolecta diamantes para aumentar tu puntuación.
- Encuentra las tres llaves para acceder a la Cámara Secreta y al enfrentamiento final.

## Controles

| Tecla | Acción |
| --- | --- |
| `A` | Moverse a la izquierda |
| `D` | Moverse a la derecha |
| `Espacio` | Saltar |
| `K` | Golpear |
| `O` | Disparar |

## Requisitos y ejecución

- Unity **6000.0.23f1** (Unity 6), según la versión indicada en `ProjectSettings/ProjectVersion.txt`.
- Abrir en Unity Hub la carpeta `GAME/New Unity Project`.
- Abrir la escena del juego desde `Assets/Juego/Scenes` y pulsar **Play** en el Editor.

Para generar una versión ejecutable, abre **File > Build Profiles** (o **Build Settings**, según la configuración del Editor), selecciona la plataforma y las escenas que correspondan al proyecto y crea el build.

## Tecnología y recursos

- **Motor:** Unity
- **Lenguaje de scripting:** C#
- **Género:** plataformas y acción 2D
- El proyecto incluye sprites, animaciones, escenarios, enemigos y recursos de interfaz dentro de `Assets`.

## Estado del proyecto

Este README resume la historia y los controles definidos para el juego. La disponibilidad de las tres llaves, los diamantes, la Cámara Secreta y el combate contra el jefe depende de que esas mecánicas estén implementadas y configuradas en las escenas del proyecto.
